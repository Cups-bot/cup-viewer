# Сервер CupViewer (этапы Г–Е)

API и сайт одним процессом: вход по почте и паролю, подписка (сайт закрыт без
оплаченного срока), токены, задания рендера, файлы на 30 дней, оплата-заглушка,
админка. Концепция —
`docs/CONCEPT-v2.md` (§3–§10). Всё работает на этом компьютере; выгрузка на
Timeweb — этап Ж.

## Запуск

Всё сразу — двойной щелчок по `start-local.bat` в корне репозитория: при первом
запуске ставит библиотеки, собирает сайт, поднимает сервер и исполнитель рендера
(черновик) — каждое в своём окне — и открывает http://127.0.0.1:8000. Что уже
работает, не дублирует. `start-local.bat stop` — остановить всё,
`start-local.bat noworker` — без рендера, `start-local.bat dev` — ещё и сборка в
режиме наблюдения (правка кода; перед коммитом — `npm run build`). Полное
качество на ноутбуке: `set CV_WORKER_PROFILE=laptop` перед запуском.

Вручную. Один раз — окружение (библиотеки из `requirements.txt`):

```bat
python -m venv server\.venv
server\.venv\Scripts\python -m pip install -r server\requirements.txt
```

Сервер (сайт и API на http://127.0.0.1:8000):

```bat
server\.venv\Scripts\python server\run.py
```

Исполнитель рендера — в соседнем окне; сам берёт задания и считает их Blender:

```bat
server\.venv\Scripts\python server\worker.py
```

Профиль исполнителя — `CV_WORKER_PROFILE`: `laptop` (по умолчанию в
`worker.py`: 256 сэмплов, полный размер), `draft` (48–64 сэмпла, 800–1000 px —
его ставит `start-local.bat`), `cloud` — GPU-сервер.

Вход — страница `login.html`: почта и пароль. Письма пока не уходят: код
сброса пароля («Забыли пароль?») печатается в консоли сервера:
`=== Код сброса пароля для name@mail.ru: 123456 ===`. Аккаунты, заведённые ещё
входом по коду, задают пароль так же — через «Забыли пароль?».

## Что где

| файл | что |
|---|---|
| `app/main.py` | приложение: API, раздача сайта (только `index.html`, `admin.html`, `login.html`, `dist/`, `css/`, `js/`, `assets/`, `catalog/`, `vendor/`; пути с `..` и скрытые файлы — 404); без оплаченного срока страницы уводят на `login.html`, данные (модели, каталог, фоны, шаблоны) — 403; заголовки безопасности, уборка раз в 10 минут |
| `app/auth.py` | вход и регистрация: почта и пароль (scrypt, не короче 8), 10 неверных за 15 минут — стоп; сброс пароля кодом (6 цифр, 10 минут, 5 попыток) — закрывает прежние сессии; одноразовые почты не принимаются |
| `app/billing.py` | тарифы подписки, оплата доступа (срок + стартовые токены до его конца; сгоревшие не оживают), пакеты токенов — только при действующем сроке; тестовая оплата |
| `app/tokens.py` | журнал токенов: кошельки paid (купленные) и welcome (стартовые подписки); кадр — сначала стартовыми, потом купленными, иначе вместе; возврат — ровно в те же кошельки |
| `app/jobs.py` | задания (только с подпиской): резерв токенов, общая очередь, не больше 3 в работе у каждого, место, ожидаемое время и «исполнитель на связи», кадры без знака, архив выбранных (ZIP), удаление пачкой, сцена кадра для «В редактор», повтор после сбоя; макет до 16384 px; API исполнителя; уборка: зависшее 3 раза и ждущее больше суток — сбой с возвратом |
| `app/admin.py` | админка: пользователи (доступ, продление вручную, начисления), тарифы, очередь, платежи |
| `app/thumbs.py` | миниатюры галереи |
| `worker.py` | исполнитель: `render/engine/run.py --job`, пониженный приоритет, 4 потока, пульс каждые 30 с |
| `data/` | база SQLite, макеты, кадры, ключ исполнителя (`worker.key`) — не в git |

## Настройки (переменные окружения)

| переменная | по умолчанию | что |
|---|---|---|
| `CV_PORT`, `CV_HOST` | 8000, 127.0.0.1 | адрес сервера |
| `CV_DATA` | `server/data` | база и файлы |
| `CV_ADMINS` | danilkakhudia@gmail.com | почты администраторов через запятую |
| `CV_SERVER` | http://127.0.0.1:8000/ | куда ходит исполнитель |
| `CV_WORKER_PROFILE` | laptop | `draft`, `laptop` или `cloud` |
| `CV_BLENDER`, `CV_THREADS` | Blender 5.2, 4 | Blender исполнителя |

Цены кадров, пакеты, сроки хранения — `app/config.py` (`PRICES`, `PACKS`, `RETENTION_DAYS`).
Тарифы подписки — в админке (вкладка «Тарифы»); пустая база получает
`DEFAULT_PLANS` из `app/config.py`.

## Проверки

```bat
server\.venv\Scripts\python -m unittest server.tests.test_flow -v
node tests\account\e2e.mjs            :: кабинет глазами человека (исполнитель — запросами)
node tests\account\e2e.mjs --real     :: то же с настоящим исполнителем и Blender (черновик)
```

`test_flow` поднимает сервер на временной базе и проходит регистрацию, пароль
и его сброс, закрытый без подписки сайт, тарифы и сгорание стартовых токенов,
резерв и возврат токенов, очередь, исполнителя, оплату, админку, а также
закрытые пути (`..`, скрытые файлы) и лимиты попыток.

Dev-сервер фронтенда (`npm run serve`) по-прежнему работает — без кабинета и
без входа: там кнопка «Задание» кладёт задание папкой в `render/jobs/` для
ручного рендера.
