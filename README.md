# 3D Cup Viewer

Небольшой просмотрщик на Three.js: показывает 3D-модель в браузере и позволяет
примерять на неё разные текстуры. Освещение — HDRI (IBL), под моделью падающая
тень без видимой плоскости.

## Запуск

Страница подгружает модули и ассеты по HTTP, поэтому открывайте её через сервер,
а не двойным кликом по `index.html`:

```bash
python -m http.server 8000
# откройте http://localhost:8000
```

## Освещение и качество рендера

Свет берётся из равнопромежуточной HDRI-карты в `assets/hdri/`. Она проходит
через `PMREMGenerator` — предварительную фильтрацию, благодаря которой глянцевые
и шероховатые материалы не «искрят»: для каждого уровня шероховатости
генерируется свой корректно размытый мип.

Карта назначается **только** в `scene.environment` и никогда в
`scene.background`. Поэтому фон остаётся управляемым плоским цветом, а модель
при этом освещена полным динамическим диапазоном HDRI.

Что ещё сделано ради качества картинки:

- ACES Filmic тонмаппинг и корректный sRGB-пайплайн;
- анизотропная фильтрация текстур по максимуму, который отдаёт видеокарта
  (значение читается с живого рендерера, а не задаётся числом);
- тень 4096×4096, камера теней плотно подогнана под модель — иначе при размере
  модели в 0.5 юнита стандартный фрустум тратит впустую почти всю карту теней и
  контактная тень становится «лесенкой»;
- `normalBias` вместо голого `bias`, чтобы убрать shadow acne без отрыва тени.

### Про размер HDRI

В папке лежат два файла:

| Файл                       | Размер | Назначение                    |
| -------------------------- | -----: | ----------------------------- |
| `pretoria_gardens_2k.hdr`  | 6.6 МБ | используется по умолчанию     |
| `pretoria_gardens_4k.exr`  |  96 МБ | исходник, оставлен как есть   |

Исходный 4K EXR — 4096×2048 в 32-битном float. Его разбор происходит в главном
потоке и подвешивает вкладку примерно на минуту. При этом выигрыша в картинке
нет: HDRI здесь только освещает модель (фоном она не показывается), а
`PMREMGenerator` всё равно сворачивает её в небольшую кубическую карту — 2K для
этого с запасом.

2K-версия получена усреднением по боксу в линейном пространстве, то есть с
сохранением энергии: суммарный вклад солнца в освещение не изменился. Формат
RGBE выбран не случайно — пик исходника ≈ 99 850, а half-float обрезал бы всё
выше 65 504 (three.js честно предупреждал об этом в консоли).

Вернуться к исходнику можно одной строкой в `js/config.js` — оба формата
(`.hdr` и `.exr`) грузятся одинаково:

```js
hdri: 'assets/hdri/pretoria_gardens_4k.exr',
```

## Два режима вращения

Это разные вещи, и сделаны они намеренно по-разному:

- **Автоповорот** крутит саму модель (`pivot.rotation.y`), камера при этом
  неподвижна. HDRI живёт в мировых координатах, поэтому блики и отражения
  остаются на месте, а стакан поворачивается под ними.
- **Мышью** вращается камера (`OrbitControls`), а модель стоит. Взгляд движется
  сквозь окружение, так что модель и свет поворачиваются вместе.

Собственный `autoRotate` у `OrbitControls` выключен — он вращал бы камеру, из-за
чего карта света «поехала» бы вместе с ней.

Скорость и включённость автоповорота — в `js/config.js`:

```js
autoRotate: { enabled: true, speed: 0.45 },  // радиан в секунду
```

## Тень без видимой плоскости

Под моделью лежит плоскость с `THREE.ShadowMaterial`. Такой материал рисует
только теневую составляющую и ничего больше, поэтому видно контактную тень, а
сама плоскость остаётся полностью прозрачной — фон читается сквозь неё. Плоскость
автоматически встаёт на нижнюю точку модели после загрузки.

```js
ground: { enabled: true, size: 20, opacity: 0.35 },
```

## Фон

Четыре варианта, переключаются кнопкой или клавишей `B`:
белый → светло-серый → серый → тёмный.

```js
backgrounds: ['#ffffff', '#e8e8e8', '#9a9a9a', '#1c1c1e'],
```

## Иконки

Иконки панели — обычные `.svg` файлы в `assets/icons/`, подключённые тегами
`<img>`:

```
assets/icons/background.svg
assets/icons/autorotate.svg
assets/icons/screenshot.svg
assets/icons/fullscreen.svg
assets/icons/texture.svg
```

Чтобы поставить свои — просто замените файл под тем же именем. Ни разметку, ни
CSS трогать не нужно. Размер задаётся переменной `--icon-size` в
`css/style.css`, а рисуются иконки как есть, своими цветами (в комплектных
залит белый `#ffffff` — панель тёмная).

## Другая модель

Перетащите файл `.glb`/`.gltf` на страницу или пропишите путь в `js/config.js`:

```js
assets: {
  model: 'assets/models/8cups.glb',
  texture: 'assets/textures/img_mokup.jpg',
}
```

Модель сама центрируется, масштабируется и попадает в кадр.

## Смена текстуры

Нажмите **Replace Texture**, перетащите картинку на страницу или вызовите из
консоли:

```js
replaceTexture('assets/textures/mockup.jpg');
```

Текстура меняется на месте — модель не перезагружается.

## Шероховатость поверхности под текстурой

`8cups.glb` приходит с `roughness: 0` на том меше, куда ложится текстура, —
это зеркало, поэтому стакан выглядит глянцевым пластиком, а не бумагой.
`roughnessMap` на материале нет, так что всё решает один скаляр:

```js
texturedSurface: {
  roughness: 0.6,   // 0 — зеркало, 1 — полностью матовая
  metalness: 0.0,
},
```

| Значение | Как выглядит                    |
| -------: | ------------------------------- |
|      0.0 | зеркало / глянцевый пластик     |
|      0.3 | лакированная поверхность        |
|      0.6 | матовая печать на бумаге        |
|      1.0 | полностью матовая, без бликов   |

Настройка применяется **только** к мешам из `texturableMeshes` — то есть ровно
к тем, куда идёт ваша текстура. Остальная геометрия (ободок, дно) сохраняет
материалы, с которыми модель была собрана. `null` вместо числа означает
«не трогать это свойство».

Подобрать значение вживую можно прямо из консоли, без перезагрузки:

```js
setRoughness(0.35);
setMetalness(0);
```

Разница заметнее всего на ободке и на скользящих углах, а на реальном дизайне
с контрастной печатью — сильнее, чем на белой заглушке.

## Управление

Зажатая кнопка мыши — вращение, колесо — зум, правая кнопка — панорамирование.
Остальное — на нижней панели и на паре клавиш:

| Действие                       | Кнопка          | Клавиша |
| ------------------------------ | :-------------: | :-----: |
| сменить фон                    | `background`    |   `B`   |
| включить/выключить автоповорот  | `autorotate`    |   `A`   |
| сохранить скриншот             | `screenshot`    |   `S`   |
| полноэкранный режим            | `fullscreen`    |   `F`   |
| заменить дизайн                | `texture`       |    —    |

## Структура

```
index.html            разметка
css/                  стили
js/config.js          настройки (камера, свет, HDRI, тень, фон, автоповорот,
                      шероховатость…)
js/main.js            точка входа
js/Viewer.js          связывает всё вместе, владеет циклом отрисовки
js/core/scene.js      сцена
js/core/camera.js     камера
js/core/renderer.js   рендерер и цветовой пайплайн
js/core/lighting.js   источники света и настройка теней
js/core/environment.js загрузка HDRI и предфильтрация (IBL)
js/core/ground.js     невидимая плоскость-ловушка теней
js/core/controls.js   OrbitControls
js/loaders/           загрузка модели и текстур
js/ui/                кнопки, горячие клавиши, drag & drop
js/utils/             общие вспомогательные функции
assets/hdri/          карта освещения
assets/icons/         svg-иконки панели управления
assets/models/        модели
```

Почти всё, что захочется поменять, лежит в `js/config.js`. Сам Three.js
подключается с CDN через import map в `index.html`.
