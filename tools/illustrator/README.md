# export-proof.jsx

Скрипт для Illustrator: в один клик превращает активный документ в текстуру с
запечённой имитацией цвета бумаги (soft-proof) и кладёт готовый sRGB PNG туда,
где его ждёт вьювер.

## Что он делает

1. Растрирует активный документ Illustrator в **плоский CMYK PSD** (числа CMYK
   сохраняются — как режим «Сохранять значения CMYK» в цветопробе).
2. Открывает его в Photoshop, **назначает выбранный профиль бумаги** (Assign, без
   изменения чисел).
3. Делает `Convert to Profile` в **sRGB** методом **Absolute Colorimetric** без
   Black Point Compression — именно эта конверсия впечатывает в пиксели оттенок
   бумаги и предел чёрной краски.
4. Сохраняет `<имя>_<тип-бумаги>.png`.

Три типа бумаги выбираются в маленьком окне при запуске: **Мелованная**,
**Немелованная**, **Мелованная + лак**.

## Настройка (один раз)

Открой `export-proof.jsx` и впиши свои данные в блоке настроек сверху:

- **`PAPERS`** — три профиля бумаги. Можно писать **имя файла**
  (`glossy_curve+blended.icm`) или **описание** из списка Photoshop
  (`Edit > Convert to Profile` → список **Profile**). Скрипт сам ищет файл в
  системных папках профилей и читает описание внутри `.icm` — Photoshop понимает
  только его, имя файла для него ничего не значит.

  Кнопка **«Проверить профили»** в окне запуска показывает по каждой записи: что
  задано, какой файл нашёлся и какое у него описание. Если там «не найден» —
  профиль не установлен в системе, и до Photoshop дело не дойдёт.
- **`OUT_FOLDER`** — куда класть PNG. `null` = рядом с исходным `.ai`. Папка
  должна существовать и быть доступной на запись: `/Mockup` — это корень диска,
  туда система писать не даст. Чтобы писать прямо в текстуры вьювера:
  ```js
  var OUT_FOLDER = '/Users/me/cup-viewer/assets/textures';   // macOS
  var OUT_FOLDER = 'C:/work/cup-viewer/assets/textures';     // Windows
  ```
- **`DPI`** — разрешение растра (по умолчанию 300).

## Установка и запуск

- Разовый запуск: `File > Scripts > Other Script…` → выбрать `export-proof.jsx`.
- Постоянно в меню: положить файл в
  `Adobe Illustrator <версия>/Presets/<язык>/Scripts/` — появится в
  `File > Scripts > export-proof`.

Требуется открытый документ Illustrator и установленный Photoshop (BridgeTalk
запустит его сам, если он закрыт).

## Если не работает

**Photoshop открыл PSD и на этом всё.** Классический случай: в `PAPERS` вписано
имя файла профиля, а Photoshop ждёт описание. Строка `d.colorProfileName = …`
падает, остальные шаги (конверсия, сохранение PNG) не выполняются. Скрипт теперь
разбирает это заранее — нажми **«Проверить профили»** и сверь, что нашлось. Любая
ошибка внутри Photoshop возвращается в Illustrator текстом, а не тишиной.

**Photoshop молчит несколько минут.** Переключись в него: скорее всего висит
модальное окно — несовпадение профилей, отсутствующие шрифты, предложение
обновиться. Скрипт ставит `displayDialogs = NO` и экспортирует PSD **без
вложенного профиля** (нетегированный CMYK открывается молча), но окна, которые
Photoshop показывает от себя, так не убрать. Если окно про профили появляется
регулярно: `Edit > Color Settings` → снять галки **Ask When Opening**.

**PNG не появился.** Проверь `OUT_FOLDER`: путь должен существовать и быть
доступен на запись. Скрипт скажет об этом до запуска Photoshop.

**Профиль не найден.** Установи `.icm` в систему: macOS —
`~/Library/ColorSync/Profiles`, Windows — правый клик по файлу → «Установить
профиль» (`System32\spool\drivers\color`). Скрипт ищет только там.

## Важные оговорки

- **Профиль CMYK-документа в Illustrator.** Числа отдельно, профиль отдельно:
  скрипт назначает профиль бумаги уже в Photoshop, поэтому один и тот же CMYK-макет
  можно прогнать под все три бумаги.
- **Точность цвета во вьювере.** Даже с запечённой пробой ACES-тонмаппинг и свет
  HDRI слегка меняют цвет на 3D-модели. Для максимально верной передачи можно
  добавить во вьювер «плоский» режим предпросмотра дизайна
  (`material.toneMapped = false` на texturable-мешах).
