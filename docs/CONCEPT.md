# Cup Viewer — концепция v1.0

> **Реконструкция.** Исходный файл концепции утерян. Этот текст восстановлен 2026-09-24 по брифам
> этапов (`docs/briefs/`), макету интерфейса и текущему коду. Нумерация § совпадает со ссылками в
> брифах. Всё, что брифы не фиксируют, — решение реконструкции; такие места помечены «(р)».
> Правки владельца продукта имеют приоритет.

## Часть I. Продукт

### §1. Что это
Браузерный 3D-просмотрщик бумажных и пластиковых стаканов с дизайном заказчика. Сотрудник типографии
собирает вид (модель, материал, макет, фон) и отдаёт клиенту ссылку; клиент смотрит свой стакан.

### §2. Для кого
- **Сотрудник** (дизайнер, менеджер) — Design Mode: всё настраивает, экспортирует, публикует.
- **Клиент** — Client Mode по ссылке: только смотрит и скачивает разрешённое.

### §3. Роли и доступ
Design Mode — только авторизованные сотрудники (allowlist). Client Mode — без авторизации, по
неугадываемому токену в ссылке. Других ролей нет.

### §4. Snapshot
Ссылка клиента указывает на **snapshot** — неизменяемый слепок состояния §36 и производных растров.
Snapshot не редактируется: новая версия — новая ссылка. Списка проектов, истории, статусов, CRM нет.

## Часть II. Design Mode

### §5. Макет — как есть
Макет ложится на модель строго по развёртке модели (`textureMapping`). Никаких сдвигов X/Y, crop,
поворота, зеркала, масштаба: правильный макет — это файл под развёртку, а не подгонка в просмотрщике.

### §6. Форматы макета
P0: JPG, PNG, PDF (первая страница). P1: AI, EPS, CDR — диалог их принимает, но отвечает сообщением
§42 «Формат не поддерживается». Тип определяется по сигнатуре файла. Лимит 100 МБ.

### §7. Раскладка
3D-вьюер занимает большую часть экрана. Сверху — верхняя панель §8; под ней сцена во всю ширину;
справа по вертикали — toolbar §21; вкладки §9 — по центру верхней панели. Боковых панелей с
постоянным содержимым нет: пикеры открываются поверх и закрываются.

### §8. Верхняя панель
Слева: знак «Cup Viewer». Центр: вкладки §9. Справа: кнопка стакана (название выбранной модели,
открывает Model Picker §10), материал (§14, только совместимые), «Загрузить макет», «Экспорт» (§20),
«Ссылка клиенту» (§31). Выбор стакана и загрузка — только здесь.

### §9. Вкладки
`3D | Развёртка | Сцена`. «Сцена» — вкладка фото-сцен §18. Вкладка — поле состояния `tab`.

### §10. Model Picker
Диалог поверх сцены: группы Бумажные / PP / PET, карточки (силуэт, название, объём, тип), поиск по
`name`, `id`, объёму и `searchTerms` (без регистра, подстрока). Пустой результат — текст и сброс.
Клавиатура: Escape закрывает, фокус заперт внутри, стрелки и Enter выбирают.

### §11. Стартовое состояние
Без сохранённой сессии — пустая сцена и действие «Выбрать стакан». Сессия (`modelId`, `materialId`,
`backgroundId`) хранится в localStorage; сам макет не восстанавливается. Клиент стартует из snapshot.

### §12. Ракурсы и камера
Пресеты `front | right | back | left | top | seam` (seam — вид на шов). Переход камеры 250–400 ms,
любой ввод пользователя его прерывает. Reset — к `front`. Пресеты общие для UI и экспорта §20.

### §13. Фоны
Студийная свёртка с лёгкой растяжкой по высоте. Пресеты в `catalog/backgrounds.json`: минимум Light,
Warm, Dark плюс прежние студийные цвета. Флаг `client: true` у 2–3 пресетов — только они доступны
клиенту. Цвет фона уходит в окружение (отсвет подложки на предмет).

### §14. Материалы
Coated, uncoated, soft-touch, kraft, PP clear, PP frosted, PET clear. Каждый физически отличим.
Совместимость задаёт модель (`materialCompatibility`, `defaultMaterial`). Клиент материал не выбирает.

### §15. Цвет важнее эффектности
Страница существует ради согласования цвета: `toneMapping = None`, `outputColorSpace = sRGB`,
экспозиция 1. Материалы, свет и постобработка не смещают цвет макета. Эффект, который уводит цвет,
не принимается, даже если «красивее». Исключение — фото-сцена, где кривую задаёт сама сцена.

### §16. Развёртка
Чистый плоский макет без разметки и технических линий: zoom, pan, fullscreen, «Скачать». Растр
развёртки — отдельный от 3D, полного разрешения (до пределов §49).

### §17. Сессия и повторная загрузка
Повторный выбор файла во время обработки отменяет предыдущую; применяется только последний.

### §18. Photo scene
Сцена — папка `catalog/scenes/<id>/`: `scene.json` (камера с FOV для кадров wide/tall, пол и масштаб
мм/единица, точка стакана, view transform, интенсивность окружения, слои теней по моделям), фоновые
снимки, `env.hdr`, запечённые тени. Индекс — `catalog/scenes/index.json`. Новая сцена = папка +
запись в индексе, без правки кода. Стакан стоит в натуральную величину; камера фиксирована.

### §19. Автоповорот
Крутится модель, камера и окружение неподвижны. Design: кнопка и клавиша A. Client: §23.

### §20. Export Center
Одно окно «Экспорт»: Изображение (PNG | JPG 0,92; 1920×1080 | 2048×2048 | текущий вид), 4 ракурса
(ZIP `front,right,back,left`), 360° (видео, опционально + кадры). Кадр без UI, стакан целиком в кадре
при любом соотношении сторон, цвет = цвет экрана. Прозрачного фона нет.

### §21. Toolbar
Постоянно: Reset, Auto rotate, Screenshot, Fullscreen. Остальное — в «•••»: фон, ракурс, поворотный
круг, справка.

## Часть III. Client Mode

### §22. Сценарий клиента
Открыл ссылку → loader §40 → стакан в медленном обороте → смотрит, крутит, меняет фон, открывает
развёртку/сцену/информацию, скачивает разрешённое. Больше ничего.

### §23. Автооборот клиента
1 оборот за 21 с. Первое взаимодействие (pointerdown, wheel, touchstart, клавиши камеры) — стоп
навсегда; снова — только кнопкой ↻.

### §24. Верх клиента
Логотип бренда, опциональный заголовок snapshot, кнопка ⓘ. Бренд задаёт логотип, акцентный цвет
(CSS-переменная), favicon, `<title>`.

### §25. Информация
Drawer ⓘ (desktop — справа, mobile — bottom sheet): объём, материал, тип печати — из каталогов.
SKU, имена файлов, пути — никогда.

### §26. Управление клиента
Облёт, zoom, reset двойным кликом/касанием. Панорамирования нет (р).

### §27. Фоны клиента
Только `client: true`, кружки-свотчи без подписей.

### §28. Сцены клиента
Вкладка «Сцена»; при нескольких сценах — переключатель. Сбой — возврат в 3D и тост §42.

### §29. Скачать (клиент)
Текущий кадр (PNG), развёртка (PNG), 360° (видео), preview (JPG 1200×1200 фронтального ракурса) (р).
Через модуль экспорта с `export = limited`.

### §30. Share
Кнопки «Поделиться» в Client Mode нет: ссылку клиент копирует из адресной строки.

### §31. Публикация
Design Mode, кнопка «Ссылка клиенту»: загружает производные растры (3D-текстура ≤ 2048 и
развёртка), создаёт snapshot, возвращает ссылку один раз. Исходник макета никогда не уходит.

## Часть IV. Архитектура

### §32. Стек
ES-модули + three.js 0.160 + esbuild. Без фреймворков, TypeScript, state-библиотек и UI-китов.

### §33. Авторизация
Magic link (Supabase Auth). Проверка `is_staff()`; не staff — экран «Нет доступа» и выход.

### §34. viewer_snapshots
`id uuid pk, token_hash text unique, state jsonb (§36 без design), texture_path, unwrap_path,
created_by uuid, created_at timestamptz, schema_version int`. Токен в открытом виде не хранится.

### §35. Хранилище
Приватный bucket `viewer-assets`, префикс `<user_id>/<snapshot>/`. Клиент получает только signed URLs
с TTL 1 ч.

### §36. ViewerState
Единственный источник истины: `modelId, materialId, backgroundId, sceneId, brandId, title, design,
tab, autoRotate, view, fullscreen`. `design = { textureUrl, unwrapUrl, width, height } | null`.
`view` — последний пресет камеры §12. Изменения батчатся в один микротаск.

### §37. Capabilities
| capability | design | client |
| --- | --- | --- |
| changeModel | ✓ | — |
| changeMaterial | ✓ | — |
| uploadDesign | ✓ | — |
| publish | ✓ | — |
| export | full | limited |
| changeBackground | все | только `client: true` |
| openScene, openUnwrap, camera, autoRotate, fullscreen | ✓ | ✓ |
Запреты логические: проверка в ModeController, а код загрузки/пикеров/публикации отсутствует в
клиентском бандле. CSS-скрытие запретом не считается.

### §38. Каталог моделей
`catalog/models.json`: `id, name, type (paper|pp|pet), wall, volumeMl, file, size {heightMm, topMm,
bottomMm}, textureMapping {materials, uv, sheet, unwrapMm [w, h]}, materialCompatibility,
defaultMaterial, printType, searchTerms`. UI не ветвится по конкретному id — только по полям.

### §39. Каталог материалов
`catalog/materials.json`: `id, name, kind (paper|plastic), params` — параметры MeshPhysicalMaterial
(roughness, relief, specularIntensity, transmission, thickness, ior, sheen, clearcoat, opacity, tint
и т. п., только применимые) + `printBlend` (`normal` | `multiply` для крафта).

## Часть V. Клиентский опыт

### §40. Loader
Этапы «Загружаем модель / Накладываем дизайн / Настраиваем материал». Процент — только реальный
(LoadingManager, Content-Length); нет данных — без процента.

### §41. Появление
Opacity 300–500 ms + лёгкое «оседание» камеры; автооборот стартует после появления.

### §42. Тексты ошибок (дословно)
| Ситуация | Текст |
| --- | --- |
| WebGL недоступен | «Ваш браузер не может показать 3D. Откройте ссылку в свежей версии Chrome, Safari, Edge или Firefox.» |
| Snapshot отсутствует | «Ссылка недействительна или устарела. Попросите менеджера прислать новую.» |
| Ссылка устарела (ассеты истекли) | «Не удалось загрузить дизайн. Обновите страницу.» |
| Макет не загрузился | «Не удалось загрузить макет. Проверьте файл и попробуйте ещё раз.» |
| Формат не поддерживается | «Этот формат пока не поддерживается. Экспортируйте макет в PDF или PNG.» |
| Файл больше 100 МБ | «Файл больше 100 МБ. Уменьшите его и загрузите снова.» |
| Модель не загрузилась | «Не удалось загрузить модель стакана. Обновите страницу.» |
| Сцена не открылась | «Не удалось открыть сцену» |
| Ошибка экспорта | «Не удалось сохранить файл. Попробуйте ещё раз.» |
| Публикация не удалась | «Не удалось создать ссылку. Попробуйте ещё раз.» |
Неблокирующие тосты: «Использована первая страница», «Пропорции макета не совпадают с развёрткой модели».

### §43. Mobile Client
Вьюер 70–80 % высоты, под ним вкладки и действия; drawer ⓘ — bottom sheet.

### §44. Onboarding
Оверлей жестов один раз (ключ `cv.onboarding.v1`). Недоступный localStorage — показывать и не падать.

## Часть VI. Устройства и производительность

### §45. Mobile Design Mode
Нижняя панель `[Стакан] [Дизайн] [Материал] [Ещё]`; «Ещё»: фон, сцена, экспорт, 360, Client View.
Model Picker и Export Center — полноэкранные bottom sheets.

### §46. Tablet
Landscape — desktop-раскладка; portrait — mobile-контролы с увеличенными sheets.

### §47. Жесты
Не конфликтуют со скроллом sheet'ов; цели нажатия ≥ 44×44 px.

### §48. Уровни качества
| | High | Medium | Low |
| --- | --- | --- | --- |
| DPR | ≤ 2 | ≤ 1,5 | 1 |
| MSAA | 4 | 2 | 0 |
| AO (GTAO) | 32 выборки | 16 | выкл |
| Карта теней | 1024 | 1024 | 512 |
| Контактная тень | 1024 | 512 | 256 |
Не меняются: геометрия, цвет, тип материала. Понижение на ходу — при FPS < 30 дольше 3 с.

### §49. Текстуры
3D ≤ 2048 px по длинной стороне (и ≤ `maxTextureSize`). Развёртка — ≤ 16 777 216 px площади и
≤ 8192 px по стороне (canvas iOS Safari); больше — даунскейл с сохранением пропорций.

### §50. Стартовая загрузка
Только UI, ядро three, выбранная модель, её текстура, студия. По требованию: сцены, HDR, экспорт,
видеоэнкодер, pdf.js, Model Picker.

### §51. Кэш
Ассеты с fingerprint — `Cache-Control: public, max-age=31536000, immutable`; HTML и ответы
`get-snapshot` — `no-store`.

### §52. Матрица совместимости
Desktop: Chrome, Edge, Firefox, Safari (две последние версии). Mobile: iPhone Safari (iOS 16+),
Android Chrome (средний сегмент), iPad Safari.

## Часть VII. Качество

### §53. Что удалить
Approval workflow целиком: «Согласовать», чек-лист, «Нужны правки», статусы, «Поделиться ссылкой»,
панель заказа, канал заказа Битрикса (`window.ORDER_DATA`, `?order=`).

### §54. Что сохранить
3D-вьюер и весь рендер, развёртку, фото-сцену, поворотный круг, скриншот, запись 360 с кадрами,
каталог стаканов, выбор картона, загрузку макета, fullscreen, горячие клавиши.

### §55. Доступность
Клавиатурная навигация по пикерам и диалогам, видимый фокус, `aria-*` у переключателей.

### §56. Язык
Интерфейс на русском. Термины: «макет», «развёртка», «стакан», «сцена».

### §57. Чек-листы приёмки
**Сотрудник**
1. Открыть Design Mode без сессии — пустая сцена, «Выбрать стакан».
2. Найти стакан поиском по объёму (`430`).
3. Выбрать стакан — модель появляется, кадр по центру.
4. Сменить материал — список только совместимых.
5. Загрузить PNG — дизайн на модели без подгонки.
6. Загрузить PDF — первая страница на модели, тост при нескольких страницах.
7. Открыть «Развёртка» — макет плоско, zoom, скачать.
8. Открыть «Сцена» — стакан в фото-сцене.
9. Сменить фон — Light/Warm/Dark.
10. Ракурс «Сбоку» — плавный переход.
11. Экспорт PNG 2048×2048 — стакан целиком, без UI.
12. Экспорт ZIP 4 ракурсов — 4 файла.
13. Запись 360 — видео.
14. Создать ссылку клиенту — ссылка скопирована.
15. Перезагрузить страницу — модель, материал и фон восстановлены, макета нет.

**Клиент**
1. Открыть ссылку — loader с этапами.
2. Стакан появляется плавно, начинается медленный оборот.
3. Первое касание останавливает оборот навсегда.
4. Кнопка ↻ возобновляет оборот.
5. Облёт и zoom работают, двойной клик — reset.
6. Логотип и акцент бренда на месте, `<title>` бренда.
7. ⓘ — объём, материал, тип печати; SKU нет.
8. Фоны — только клиентские свотчи без подписей.
9. «Развёртка» — макет плоско с zoom.
10. «Сцена» — фото-сцена; при сбое — возврат в 3D и тост.
11. «Скачать» — текущий кадр PNG.
12. «Скачать» — развёртка PNG.
13. «Скачать» — 360° видео.
14. «Скачать» — preview JPG.
15. Нет выбора модели, материала, загрузки, публикации — ни в UI, ни в коде бандла.
16. Битая ссылка — экран «Ссылка недействительна…».
17. Без WebGL — экран §42, без чёрного канваса.

### §58. Рендер не деградирует
Любая правка рендера проверяется `render:check` до и после. Пороги: доля отличающихся пикселей
≤ 0,1 %, mean ΔE00 ≤ 0,5, p99 ΔE00 ≤ 2,0. Эталоны переснимаются только с «ок» человека.

### §59. Приватность клиента
`<meta name="referrer" content="no-referrer">`, `noindex`. В DOM, консоли и сети клиента нет путей
хранилища, имён исходников, SKU, ключей.

### §60. Один движок, одно состояние, две оболочки
Один renderer, одна сцена, один ViewerState. Design и Client — разные оболочки и бандлы над общим
движком. Второго renderer/scene под Client Mode нет.
