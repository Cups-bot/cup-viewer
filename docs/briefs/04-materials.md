# Этап 04 — Каталог материалов

Самый чувствительный к рендеру этап. Бюджет размышления: think hard.
Читать: §14, §15, §39, §58; аудит раздел 3.

## Цель
Дизайнер выбирает coated, uncoated, soft-touch, kraft, PP clear, PP frosted, PET clear; каждый материал физически отличим, а цвета макета не уезжают.

## Требования
1. Материалы — записи `catalog/materials.json` с параметрами MeshPhysicalMaterial: roughness, normal/relief (карта + масштаб), specularIntensity, transmission, thickness, ior, sheen, clearcoat — только применимые. Модель хранит `materialCompatibility` и `defaultMaterial`.
2. Существующие материалы — параметры не меняются. Новые — стартовые значения подбираешь сам и обосновываешь каждое одной строкой. Числа из чужих проектов без обоснования не брать.
3. Kraft: печать без белой подложки: белые и прозрачные области макета показывают крафт, краски ложатся умножением (решение владельца 2026-09-24).
4. Сохранение цвета: для coated/uncoated/soft-touch mean ΔE00 плашек фикстуры (б) на фронтальном кадре относительно coated ≤ 2,0; для kraft и пластиков — ΔE в отчёт без порога.
5. Цена производительности: transmission даёт дополнительный проход — замерь FPS на кадре PP clear против coated (dev-оверлей), числа в отчёт.
6. Material picker — в верхней панели Design Mode (§8), показывает только совместимые с моделью.

## Не-цели
- свет, окружение, тени, toneMapping — не трогать
- материалы в Client Mode не выбираются (§14)
