# Этап 03 — Оболочка Design Mode, Model Picker, фоны, загрузка JPG/PNG/PDF

Две сессии с `/clear` между ними: 03a (оболочка) и 03b (загрузка). Бюджет размышления: think.
Читать: §5–§13, §16, §21; аудит разделы 4, 10.

## 03a — оболочка
### Цель
Сотрудник видит 3D на большей части экрана, выбирает стакан из каталога с поиском и переключает фоны и ракурсы.

### Требования
1. Раскладка §7, верхняя панель §8, вкладки 3D | Развёртка | Сцена §9, toolbar §21: постоянно Reset, Auto rotate, Screenshot, Fullscreen; остальное в «•••». Выбор стакана и загрузка — только в верхней панели.
2. Стартовое состояние: при отсутствии сохранённой сессии — пустая сцена с действием «Выбрать стакан». Сессия = `modelId`, `materialId`, `backgroundId` в localStorage; сам дизайн не восстанавливается.
3. Model Picker: группы Бумажные / PP / PET, карточки (превью, название, объём, тип), поиск по `name`, `id`, объёму и `searchTerms` без учёта регистра и с подстрокой: `430`, `dw90`, `двухслойный`, `PP`, `PET` находят ожидаемое. Синонимы — только в каталоге. Пустой результат — текст + сброс поиска. Escape закрывает, фокус удерживается внутри, стрелки и Enter работают.
4. Фоны §13: Light, Warm, Dark — параметры студийного sweep в `catalog/backgrounds.json`, флаг `client: true` у 2–3 пресетов для Client Mode. Текущий sweep остаётся одним из пресетов с прежними параметрами.
5. Ракурсы §12: API пресетов камеры `front | right | back | left | top | seam` + пункт «Ракурс» в «•••». Переход 250–400 ms, прерывается пользовательским вводом. Эти же пресеты использует этап 05.
6. Развёртка §16: чисто, без разметки; fullscreen, скачать, zoom.

## 03b — загрузка дизайна
### Цель
Сотрудник загружает JPG/PNG/PDF и сразу видит дизайн на выбранной модели без ручной подгонки.

### Требования
1. Тип файла — по сигнатуре (magic bytes), не по расширению. Лимит 100 МБ. AI/EPS/CDR принимаются диалогом, но дают сообщение: «Этот формат пока не поддерживается. Экспортируйте макет в PDF или PNG.» (P1 — §6).
2. PDF: `pdfjs-dist` (разрешённая зависимость), worker грузится лениво при первом PDF. Растрируется страница 1; при нескольких страницах — тост «Использована первая страница». Масштаб растра считается от развёртки модели из `textureMapping`.
3. Из одного источника строятся два растра: 3D-текстура ≤ 2048 px и unwrap полного разрешения. Лимит unwrap — ≤ 16 777 216 px по площади и ≤ 8192 px по стороне (ограничение canvas в iOS Safari; проверь на устройстве, число в отчёт). Превышение — даунскейл с сохранением пропорций, не ошибка.
4. Наложение — только по `textureMapping` модели, как сейчас. Расхождение пропорций макета и развёртки > 2 % — неблокирующий тост «Пропорции макета не совпадают с развёрткой модели».
5. Прозрачность PNG — поведение как сейчас (аудит раздел 10).
6. Повторная загрузка во время обработки отменяет предыдущую (токен поколения / AbortController); устаревший результат не применяется. Object URL и canvas освобождаются, текстуры `dispose()`.
7. Файл остаётся локальным до публикации (этап 06). Никаких сетевых запросов с макетом.
8. Ошибки — дословно §42 «Макет не загрузился».

### Не-цели
- никакого X/Y, crop, rotate, mirror, масштаба (§5)
- никакой конвертации цвета поверх того, что делает pdf.js

- [ ] быстрый двойной выбор файла: применился только последний
