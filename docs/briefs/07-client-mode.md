# Этап 07 — Client Mode

Бюджет размышления: think hard.
Читать: §11, §22–§30, §40–§44, §37.

## Цель
Клиент открывает ссылку, видит loader, затем свой стакан с нужным дизайном и материалом в медленном обороте и может только смотреть, крутить, менять 2–3 фона, открывать развёртку, сцену, информацию и скачивать разрешённое.

## Требования
1. View-вход читает `?v=<token>` → `get-snapshot` → ViewerState из snapshot → ModeController(client). Отсутствует/404 — экран §42 «Snapshot отсутствует».
2. Loader §40: этапы «Загружаем модель / Накладываем дизайн / Настраиваем материал»; процент — только реальный (LoadingManager, `Content-Length`), иначе без процента. Переход §41: opacity 300–500 ms + лёгкое settling камеры; autorotate стартует после появления.
3. Autorotate: 1 оборот за 21 с. Первый pointerdown, wheel, touchstart или клавиша управления камерой — стоп навсегда; повтор — только кнопкой ↻.
4. Верх §24: логотип бренда, опциональный title, ⓘ. Бренд задаёт логотип, CSS-переменную акцента, favicon, `<title>`. Drawer ⓘ §25 (desktop справа, mobile bottom sheet): объём, материал, тип печати — из каталогов. SKU нет.
5. Фоны: только `client: true` из каталога, swatches без подписей (§27). Сцены: вкладка «Сцена», при > 1 — переключатель (§28). Сбой сцены — возврат к 3D Studio + тост «Не удалось открыть сцену».
6. Скачать §29: текущий кадр, развёртка, 360°, preview — через модуль экспорта с capability `export = limited`.
7. Mobile §43–§44: viewer 70–80 % высоты; onboarding-оверлей жестов один раз, ключ `cv.onboarding.v1` в localStorage (недоступный localStorage — показывать и не падать).
8. WebGL недоступен — проверка до загрузки ассетов, экран §42 дословно, без чёрного canvas.
9. Утечки: `<meta name="referrer" content="no-referrer">`, `<meta name="robots" content="noindex">`. В DOM, консоли и сетевых запросах нет путей storage и имён исходников.
10. Все тексты ошибок — дословно §42.
