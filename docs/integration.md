# Подключение к Битриксу: данные заказа

Страница согласования — витрина под конкретный заказ. Всё, что меняется от
ссылки к ссылке (модель, дизайн, картон, тексты справа), приходит извне; в коде
лежат только значения по умолчанию.

## Что можно передать

Все поля необязательны — чего нет, берётся из `DEFAULT_ORDER` в
`js/data/order.js`.

| Поле        | Тип     | Что делает                                                        |
| ----------- | ------- | ----------------------------------------------------------------- |
| `sku`       | строка  | Номенклатура. По ней подбирается 3D-модель (`DW80-280` и т.п.)     |
| `model`     | строка  | Прямой путь к `.glb`. Задан — важнее `sku`                         |
| `texture`   | строка  | Путь к макету. Ложится на модель и открывается во вкладке «Развёртка» |
| `paper`     | строка  | `coated` / `uncoated` (принимает и «мелованный» / «немелованный») |
| `roughness` | число   | Шероховатость 0…1 вручную. Задана — важнее `paper`                 |
| `status`    | строка  | Текст плашки состояния                                             |
| `title`     | строка  | Заголовок панели (он же `<title>` вкладки)                         |
| `lead`      | строка  | Абзац под заголовком                                               |
| `spec`      | массив  | Строки таблицы: `[{ label, value }, …]`, сколько угодно            |
| `checklist` | массив  | Пункты чек-листа перед печатью: массив строк                       |
| `note`      | строка  | Мелкий текст-оговорка под кнопками                                 |

## Способ 1 — печатать данные в страницу (рекомендуется)

Шаблон Битрикса выводит объект **до** подключения `js/main.js`:

```html
<script>
  window.ORDER_DATA = {
    sku: 'DW80-280',
    paper: 'uncoated',
    texture: '/upload/orders/2431/design.png',
    status: 'Ожидает вашего согласования',
    title: 'Посмотрите свой стакан вживую',
    spec: [
      { label: 'Тип',    value: 'Двухслойный' },
      { label: 'Объём',  value: '250 мл (до 280 мл)' },
      { label: 'Печать', value: 'Офсет' },
      { label: 'Тираж',  value: '5 000 шт.' }
    ],
    checklist: [
      'Логотип и его пропорции соответствуют брендбуку',
      'Цвета в макете: Pantone 485 C и 100% чёрный'
    ]
  };
</script>
<script type="module" src="js/main.js"></script>
```

Ни одного лишнего запроса: данные уже в HTML персональной ссылки.

## Способ 2 — запрос за данными

Ссылка вида `/viewer/?order=2431`. В `js/config.js` указывается адрес, из
которого забрать JSON (`{id}` подставляется из адреса):

```js
order: {
  endpoint: '/local/api/viewer-order.php?id={id}',
},
```

Ответ — тот же объект, что и в способе 1. Если запрос не удался, страница
покажет значения по умолчанию, а не пустоту.

## Способ 3 — параметры адреса (для проверки руками)

Перекрывают всё остальное, удобно проверить позицию без бэкенда:

```
?sku=DW80-280&paper=uncoated&texture=/upload/design.png
?roughness=0.45
```

## Номенклатура → модель

Правится в `js/data/catalog.js`:

```js
export const MODELS = {
  'DW80-280': 'assets/models/8cups.glb',
  'DW80-250': 'assets/models/8cups.glb',
};
```

Если точного ключа нет, номенклатура разбирается по префиксу (`DW…`, `SW…`), а
если и это не сработало — грузится `FALLBACK_MODEL`, и в консоль уходит
предупреждение. Что именно сработало, видно в `window.cupOrder.modelMatchedBy`:
`sku`, `pattern`, `explicit` или `fallback`.

## Картон → шероховатость

Там же, в `js/data/catalog.js`:

```js
export const PAPER_TYPES = {
  coated:   { label: 'Мелованный',   roughness: 0.2 },
  uncoated: { label: 'Немелованный', roughness: 0.8 },
};
```

Мелованный лощёный — собранный блик (0.2), немелованный рассеивает свет (0.8).
Значение уходит в материал меша под дизайном. Добавить третий вид картона —
дописать строку сюда.

## Проверка из консоли

```js
cupOrder                                  // что применилось
applyOrder({ paper: 'uncoated' })         // подменить на лету
applyOrder({ sku: 'SW80-250' })           // другая модель
setRoughness(0.35)                        // покрутить шероховатость руками
```
