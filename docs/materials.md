# Материалы: параметры и почему они такие

Данные — `catalog/materials.json`. Параметры прежних материалов (coated, uncoated,
pp-frosted) перенесены байт в байт и здесь не обсуждаются — их обоснование в
[`rendering.md`](rendering.md). Ниже — стартовые значения новых материалов (этап 04),
по строке на значение. Числа подобраны под студию вьювера, а не взяты из чужих проектов.

## Soft-touch (`soft-touch`, бумага)

| Параметр | Значение | Почему |
| --- | --- | --- |
| roughness | 0.92 | ламинат soft-touch даёт блеск < 5 GU при 60° — матовее немелованного (0.85) |
| relief | 0.05 | плёнка закрывает волокно: процедурного рельефа почти нет |
| reliefScale | 42 | как у мелованного: крупность зерна не важна при такой силе |
| normalScale | 0.35 | собственное волокно модели под плёнкой едва читается — чуть сильнее мелованного (0.3) |
| sheen | 0.12 | бархатный ворс плёнки даёт подсвет по силуэту; сильнее нельзя — sheen поднимает тёмные плашки (при 0.35 mean ΔE00 к coated 4.8, при 0.12 — 1.76 ≤ 2.0) |
| sheenRoughness | 0.3 | узкий sheen собирается у силуэта и почти не трогает лицевую сторону, где сверяют цвет |
| sheenColor | #ffffff | ворс не тонирует: цвет макета не уводится |
| (material) | Physical | sheen есть только у MeshPhysicalMaterial — на время soft-touch материал печати подменяется физической копией, прежние материалы остаются MeshStandardMaterial |

## Крафт (`kraft`, бумага, `printBlend: multiply`)

| Параметр | Значение | Почему |
| --- | --- | --- |
| boardColor | #b08a60 | небелёный бурый картон: L\* ≈ 60, b\* ≈ 25 — середина типичного диапазона крафта |
| printBlend | multiply | печать без белил (решение владельца): краска — светофильтр над картоном, белое и прозрачное = картон |
| roughness | 0.9 | небелёный картон без покрытия — самый матовый из бумажных |
| relief | 0.6 | волокно крафта грубее немелованного (0.55) |
| reliefScale | 14 | зерно крупнее немелованного (16) |
| normalScale | 1.8 | собственное волокно модели заметнее, чем у немелованного (1.4) |

## PP прозрачный (`pp-clear`, пластик)

| Параметр | Значение | Почему |
| --- | --- | --- |
| opacity | 0.14 | литой PP пропускает большую часть света, но с дымкой: стенка видна, фон сквозь неё — тоже |
| roughness | 0.08 | поверхность литья глянцевая |
| clearcoat / clearcoatRoughness | 1 / 0.04 | чёткие отражения софтбоксов — по ним глаз и узнаёт прозрачный пластик |
| sheen | 0 | рассеяния в толще, как у молочного, нет |
| ior | 1.49 | показатель преломления полипропилена → F0 ≈ 0.039 |
| color | #ffffff | стенка не тонирует печать |
| (подход) | альфа, не transmission | как у молочного PP: transmission показывает сквозь стенку только непрозрачное, и задняя стенка пропадает (разбор — rendering.md); замер цены transmission — в отчёте этапа |

## PET прозрачный (`pet-clear`, пластик)

| Параметр | Значение | Почему |
| --- | --- | --- |
| opacity | 0.08 | PET прозрачнее PP: дымки почти нет |
| roughness | 0.03 | выдувной PET почти зеркальный |
| clearcoat / clearcoatRoughness | 1 / 0.02 | блики собраннее, чем у PP |
| ior | 1.575 | показатель преломления PET → F0 ≈ 0.05: отражения ярче, чем у PP |

PET-моделей в каталоге пока нет, поэтому `pet-clear` ни одной модели не назначен;
в render:check он снимается на геометрии PP-500 как замена.

## Замеры (этап 04, 2026-09-24)

ΔE00 по 9 плашкам фикстуры (b) на фронтальном кадре, SwiftShader (`node tests/render/patches.mjs`):

| Материал | ΔE00 к coated, mean / max | ΔE00 к цвету плашки, mean | Порог |
| --- | --- | --- | --- |
| coated | 0.00 / 0.00 | 7.16 | — |
| uncoated | 1.55 / 5.41 | 7.15 | ≤ 2.0 ✓ |
| soft-touch | 1.76 / 6.03 | 7.54 | ≤ 2.0 ✓ |
| kraft | 21.87 / 34.28 | 28.27 | без порога: печать без белил по бурому картону |

PP-500, к pp-frosted: pp-clear 3.29 / 11.91, pet-clear 3.09 / 11.29 (к цвету плашки 7.16 и 7.29;
pp-frosted — 9.05). Максимумы — на чёрной плашке, сквозь которую у прозрачной стенки видна
задняя сторона.

Производительность (Chrome, Radeon, D3D11, 1440×900, без ограничения частоты кадров, медиана трёх
замеров): coated 118 кадр/с · pp-frosted 143 · pp-clear 143 · pp-clear на transmission 130.
Transmission стоит ~9 % кадра на лишний проход преломления; каталог его не использует.
