# PET-стаканы Ø95

Прозрачные стаканы Polyer (Стиролпласт) с горлом Ø95, у MyCups — шифры PG95 по
объёму до края.

| шифр | номинал | до края (по модели) | Ø верх / дно × H | откуда размеры |
|---|---|---|---|---|
| PG95-400 | 300 мл | 400 (≈412) | 95 / 57 × 107 | шаблон MyCups PG95-400-P, 1:1 |
| PG95-520 | 400 мл | 520 (≈506) | 95 / 60 × 128 | шаблон MyCups PG95-520-P, 1:1; сверен с образцом «400ml» |
| PG95-600 | 500 мл | 600 (≈600) | 95 / 60 × 152 | каталог Polyer + поставщик; верх и дно — от PG95-520; сверен с образцом «500ml» |

Профили — `profiles.json`, эскиз и разбор — `docs/ref/PET_Polyer_400.md`.

## Собрать

```bat
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P cups\pet\build_pet.py
```

С вашим макетом (две стороны, картинки в размер поля печати):

```bat
... -P cups\pet\build_pet.py -- --only PG95-520 --art-a сторонаА.png --art-b сторонаБ.png
```

На каждый стакан в `cups/pet/<шифр>/`: `.blend` для раннера, `.glb` для
просмотрщика, сведённая текстура печати и `verify.json` с размерами и объёмом.

## Как устроено

- Стенка — оболочка 0,3 мм, кромка завальцована валиком в габарите шаблона
  (2 мм по высоте, Ø95).
- Дно по фото образцов: плоское опорное кольцо 5,6 мм, внутри утопленный на
  1 мм диск с клеймом. Клеймо — рельефом (bump 0,2 мм) по карте высот
  `art/<шифр>_bottom.png` из `make_bottom_marks.py`: объём («400ml», как на
  образце), PET-1, «бокал-вилка», номер гнезда формы (27 и 16 — с образцов, 08 —
  условный). Знак производителя в центре не рисуется: нужен его вектор —
  положите `art/<шифр>_bottom_logo.png`, и он встанет в центр при сборке.
- Материал `PET`: прозрачный, IOR 1,575, почти зеркальный. `PET_Print` — тот же
  PET, поверх — непрозрачная краска по альфе текстуры печати, только на
  наружной стороне стенки.
- Печать только с двух сторон, А и Б, как в шаблоне MyCups. Сторона А смотрит в
  камеру раннера. Поле: ширина 50 мм по стенке, высота по шаблону (PG95-400 —
  44 мм, PG95-520 — 63,5 мм, PG95-600 — 87,5 мм, оценка). Макет кладётся без
  искажений: ширина считается по дуге на своём радиусе.
- Обе стороны сводятся в одну текстуру на развёртке `UVMap` (u — азимут, шов
  на +X между сторонами; v — высота z/H).
- Тестовый макет — `make_test_art.py` → `art/`.

## В сценах

В раннере (`source/plast/mockup/params/shots.json`) стаканы записаны с
`material: own`: общий материал PP на них не накладывается.

```bat
blender -b --factory-startup -P source\plast\mockup\run.py -- --set studio --cup PG95-520 --render
```

`--print` и `--art` раннера на PET не действуют: свой макет задаётся при сборке
стакана (см. выше). В панели это будет одно поле «макет стороны А / Б».
