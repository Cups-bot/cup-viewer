# Стаканы 410, 500 и 650 мл — модели, материал, съёмка

Три пластиковых стакана по чертежам завода (252215, 252214, 252213). Каждый
построен параметрически по размерам изделия, всем сделан материал молочного
полипропилена, на них надевается макет печати, и они снимаются в готовых
интерьерных сценах.

Работа разложена на две самостоятельные части плюс инструменты сверки:

```
   чертежи PDF          3D завода (.stp, .obj)
        │                        │
        ▼                        ▼
   ┌──────────────────────────────────┐
   │  cup410 / cup500 / cup650        │  модели и две развёртки у каждой
   │  движок один: product/cup500/src         │
   └──────────────────────────────────┘
        │                        │
        │  стакан + развёртки    │  отчёт сверки
        ▼                        ▼
   ┌──────────────┐        ┌──────────┐
   │   mockup    │        │  check   │  сверка с геометрией завода
   └──────────────┘        └──────────┘
        │
        ▼
   blend-файлы и картинки
```

---

## 1. Карта папок

| папка / файл | что там | трогать? |
|---|---|---|
| `product/cup410/`, `product/cup500/`, `product/cup650/` | модели стаканов: параметры и вывод | параметры менять можно |
| `product/cup500/src/` | **движок построения, общий для всех трёх** | осторожно |
| `mockup/` | подстановка стакана в сцены BlenderKit и печать | **основная рабочая папка** |
| `product/check/` | сверка моделей с геометрией завода, обмер, извлечение клейма | по требованию |
| `ref/` | 12 фотографий реальных стаканов, по ним делался материал | справочник |
| `assets/` | локальный кэш ассетов BlenderKit, создаёт сам аддон | не трогать |
| `_архив/` | промежуточные снимки `1.blend`…`3.blend` и убранный `shot500` | можно удалить |
| `4.blend` | пять ассетов BlenderKit в одном файле, источник сцен | нужен |
| `Cup …-2D-….pdf` (3 шт.) | чертежи изделий, 1:1, A3 | источник истины |
| `Cup …-3D-….stp` / `.obj` (3 шт.) | 3D изделий от завода | источник истины |
| `cup-scenes-art-direction-ru.*` | ваши материалы по арт-дирекшену сцен | ваше |

**Что нужно в повседневной работе:** папка `mockup`, в ней `art/` для макетов
и семь `.bat` файлов, которыми всё запускается.

## 2. Быстрый старт

Всё двойным щелчком из папки `mockup`. Печатать в терминале ничего не нужно.

| хочу | что делать |
|---|---|
| поставить новый дизайн | положить файл в `mockup/art/` как `design.png`, щёлкнуть `СОБРАТЬ.bat` |
| сменить объём стакана в сценах | `СТАКАН 410.bat`, `СТАКАН 500.bat` или `СТАКАН 650.bat` |
| полная запечатка вместо прямоугольной | `РЕЖИМ - ПОЛНАЯ ЗАПЕЧАТКА.bat` |
| вернуть прямоугольный макет | `РЕЖИМ - ПРЯМОУГОЛЬНЫЙ МАКЕТ.bat` |
| получить картинки, а не только файлы | `СОБРАТЬ И ОТРЕНДЕРИТЬ.bat`, около 25 минут |
| сделать одну сцену | перетащить `.bat` в окно терминала и дописать `living`, `water`, `podium` или `spotlight` |

Выбор объёма и режима печати **запоминается**: после переключения обычная
сборка и рендер работают уже с ним, разнобоя не бывает.

Результат — в `mockup/out/`: четыре `.blend` и, если запускали рендер,
четыре `.png`.

Открыв `.blend`, печать видно в режиме **Material Preview** или **Rendered**
(клавиша `Z`). В сплошном режиме её не видно: печать сделана узлами материала.

## 3. Три стакана

### 3.1 Размеры

Всё замерено из 3D завода, чертёж служил сверкой.

| величина | 410 | 500 | 650 |
|---|---|---|---|
| высота, мм | 111.5164 | 135.3000 | 178.8500 |
| диаметр по венчику, мм | 89.0042 | 89.0042 | 89.0042 |
| диаметр дна, мм | 57.4730 | 56.6800 | 56.5266 |
| полуугол конуса | 6.5916° | 5.6833° | 4.2732° |
| толщина стенки, мм | 0.510 | 0.500 | 0.600 |
| объём материала, см³ | 14.53 | 16.90 | 25.53 |
| масса при 0.905, г | 13.15 | 15.30 | 23.11 |
| объём до края, мл | 420.6 | 508.7 | 665.1 |
| рёбер расстыковки | 4 | 4 | 4 |
| шаг вложения в стопке, мм | 5.75 | 6.90 | 10.33 |
| рельеф клейма, мм | 0.25 | 0.25 | 0.25 |

Венчик у всех трёх одинаковый — они под одну крышку и одну стопку. А толщина
стенки разная: у 650 она 0.60 мм.

Сетка у всех одна и та же: 29 495 полигонов, 27 860 вершин, n-гонов нет,
немногообразных рёбер нет, вывернутых граней нет, растяжение UV 1.0001.

Клеймо у каждого своё, извлечено со своего чертежа: площадь знаков
58.3 / 60.7 / 60.9 мм². Рельеф оставлен 0.25 мм — в изделии он 0.10, но
заказчик выбрал более выраженный.

### 3.2 Сверка с геометрией завода

```bash
py -3.11 product/check/compare_official.py 410 > product/check/report_410.txt
```

Аргумент — объём: `410`, `500` или `650`. Blender не нужен, STEP разбирается
напрямую. Последние отчёты лежат рядом.

| что сверялось | 410 | 500 | 650 |
|---|---|---|---|
| высота | 0.0001 мм | 0.0000 | 0.0000 |
| диаметр дна | 0.0002 мм | 0.0000 | 0.0002 |
| полуугол конуса | 0.0020° | 0.0013° | 0.0013° |
| радиус конуса на z=120 | 0.0000 мм | 0.0008 | 0.0001 |
| толщина стенки | совпадает | совпадает | совпадает |
| объём материала | +0.80 % | +0.48 % | −0.87 % |

Расхождение по объёму — доли процента: часть от приближённой геометрии
литника, часть от разной густоты присланных триангуляций.

Отдельно подтвердилось, что **выступ у дна — четыре ребра, а не кольцо**, на
азимутах 0, 90, 180 и 270°. Это была самая дорогая ошибка в начале работы.

### 3.3 Состав папки стакана

| файл | что делает |
|---|---|
| `params/cup_NNNml.json` | единственный источник размеров, у каждого числа помечено происхождение |
| `params/bottom_marking.json` | клеймо дна, извлечённое со своего чертежа |
| `run.py` | тонкая обёртка: свой вывод и свои имена файлов, движок общий |
| `out/verify.json` | отчёт сверки; из него `mockup` берёт размеры полей |
| `out/*.blend` | собранная модель |
| `out/*.obj`, `*.glb` | экспорт |
| `out/preview.png`, `uv_layout.png` | превью и развёртка |

Запуск:

```bash
blender -b -P product/cup410/run.py -- --verify --render --export --blend
```

Ключи: `--verify`, `--render`, `--export`, `--blend`, `--no-build`,
`--params`. Коды возврата: `0` — успех, `2` — ошибка конфига, `3` — сверка не
прошла.

### 3.4 Движок один на всех

Код построения лежит в `product/cup500/src` и не содержит ни одного размерного
литерала — всё приходит из JSON. Папки `cup410` и `cup650` — не копии проекта,
а тонкие обёртки: они подменяют каталог вывода и имена файлов, а движок
импортируют как библиотеку.

Чтобы завести четвёртый объём, нужно: снять размеры (`product/check/measure_part.py`),
собрать конфиг по образцу, извлечь клеймо (`product/check/extract_marking_any.py`) и
добавить папку с такой же обёрткой.

### 3.5 Две развёртки у каждого

| слой | что это | для чего |
|---|---|---|
| `UVMap` | развёртка конуса кольцевым сектором | полная запечатка |
| `UVPrint` | прямоугольное поле шелкографии | обычные макеты |

Одной не обойтись: конус без искажений разворачивается только сектором, а
макеты на засветку сеток отдают прямоугольником.

## 4. `mockup` — стакан в готовых сценах

Скрипт открывает сцену BlenderKit, убирает «героя» — предмет, ради которого
сцена собрана, — ставит на его место наш стакан с макетом и сохраняет
отдельный `.blend`.

| ключ | сцена | что в кадре | стакан |
|---|---|---|---|
| `living` | Modern Sonos Bluetooth Speaker | тумба, лампа, растение, полосы света | вертикально |
| `water` | Perfume Bottle | бирюзовая вода с кругами | левитирует с наклоном |
| `podium` | Perfume Product Display | мраморная плита и белая лента | вертикально |
| `spotlight` | Studio Product Spotlight Scene | тёмная студия, пятно света | вертикально |

Подробности — в [../README.md](../README.md).

## 5. Печать

Два режима, переключаются двойным щелчком; поле считается от выбранного
стакана.

| стакан | поле по высоте | область краски | пропорция макета | зазор на стыке |
|---|---|---|---|---|
| 410 | z 8.00…93.68 | 202.48 × 86.25 мм | 2.348 : 1 | 15.00 мм |
| 500 | z 8.00…117.46 | 203.04 × 110.00 мм | 1.846 : 1 | 14.26 мм |
| 650 | z 8.00…161.01 | 202.27 × 153.44 мм | 1.318 : 1 | 15.00 мм |

Отступы одинаковые у всех: 8 мм снизу и 17.84 сверху. Поле задано именно
отступами, а не высотой, — иначе на низком стакане оно вылезает за венчик.

Формат макета по умолчанию равен реальной области печати, и рисунок ложится
один в один. Исключение — 500 мл: там оставлены принятые **220 × 110 мм**, и
макет сжимается по ширине на 7.71 %, потому что запечатка шире 203 мм на этом
стакане физически не помещается.

Для полной запечатки в `mockup/art/` лежат шаблоны развёртки:
`cone_template.png` (500), `cone_template_410.png`, `cone_template_650.png`.

Полностью — в [ПЕЧАТЬ.md](ПЕЧАТЬ.md).

## 6. Инструменты в `product/check/`

| файл | что делает |
|---|---|
| `compare_official.py <мл>` | сверка модели с 3D завода |
| `measure_part.py <мл>` | обмер изделия: габариты, конус, стенка, рёбра, каркас профиля |
| `extract_marking_any.py <pdf> <json> [r_дна]` | клеймо дна из чертежа; центр вида находит сам |
| `report_*.txt` | последние отчёты сверки |

Извлечение клейма требует PyMuPDF — он есть в Python 3.10 на этой машине,
поэтому запускать его надо через `python`, а не `py -3.11`.

## 7. Что где настраивается

| хочу поменять | где |
|---|---|
| размеры стакана | `cupNNN/params/cup_NNNml.json`, пересобрать |
| объём стакана в сценах | `mockup/params/shots.json`, ключ `cup_key`, или `.bat` |
| макет и режим печати | там же, раздел `print` |
| отступы поля печати | там же, `print.rect.band` |
| формат макета объёма | там же, `cups.<объём>.field_mm` |
| материал полипропилена | там же, раздел `pp` |
| размер и наклон стакана в сцене | там же, `height_scale`, `offset`, `rotation_deg` |
| качество рендера | там же, `samples` и `resolution` |

У каждого значения в конфигах есть запись в карте `_src`: помечено, взято ли
оно с чертежа, из 3D завода, из требований заказчика, подобрано мной или
посчитано. Это сделано, чтобы через месяц было понятно, откуда взялось число.

## 8. Грабли, на которые уже наступили

**Выступ у дна — не сплошное кольцо.** На чертеже сечение проходит через два
из четырёх рёбер, и это читается как поясок. Пока модель считала его кольцом,
масса была 16.42 г вместо 15.38. Подтверждено потом по 3D завода.

**В чертеже два вложенных стакана.** В сечении C-C контур продублирован со
смещением 6.90 мм — это шаг вложения, а не деталь одного стакана. Высота
сначала читалась как 142.20 вместо 135.30.

**Окружности в PDF заданы кривыми Безье.** Если брать только опорные точки,
окружности в гистограмму радиусов не попадают вообще.

**Клеймо приходится отбирать от линий чертежа.** У 650 на дне штриховые
линии: каждый штрих — отдельный фрагмент, и они лезут в клеймо вместе с
текстом. Отбор идёт по двум признакам: знак мал по габариту, а линия чертежа
держит постоянный радиус от оси и лежит в пучке таких же.

**`matrix_world` у только что открытого файла не пересчитан.** Для сцены,
которая не была активной, объект, привязанный к пустышке, показывает габарит
в нуле. Из-за этого стакан уезжал под пол.

**Плотность объёмного поглощения зависит от масштаба.** Сцены BlenderKit
смоделированы в масштабах до 23:1. Плотность имеет размерность 1/длина, а
радиус подповерхностного рассеяния задан в мировых единицах — обе величины
пересчитываются автоматически, по одному разу на материал.

**Поле печати нельзя задавать высотой.** Заданное числом 110 мм, оно на
стакане 410 давало отступ сверху минус 5.76 мм. Задаётся двумя отступами.

**`cmd.exe` читает `.bat` в кодировке консоли, а не в UTF-8.** Русский текст
в UTF-8 ломает разбор команд. Файлы `.bat` сохранены в CP866.

## 9. Чего нет

* **Наполнение стакана.** Напиток, лёд и запотевание убраны вместе с проектом
  `shot500` — заказчик переделывает их заново. Материал полипропилена из него
  перенесён в `mockup/bk/material.py` со своими параметрами, поэтому сцены
  от той папки больше не зависят.
* Печать не наносится на дно и на клеймо.
* Тон-маппинг в сценах BlenderKit оставлен авторский: три сцены на Filmic,
  одна на AgX. Это часть их готового вида.
* Вес с чертежей 410 и 650 не считывается: в PDF нет текстового слоя. В
  конфигах стоит расчётный, из объёма 3D завода при плотности 0.905.
