# Стаканы 410 / 500 / 650 мл

Параметрические модели изделий, сверка с заводской геометрией, печать макетов и
съёмка мокапов в Blender.

## Начать здесь

**Двойной щелчок по `ПАНЕЛЬ.bat`** — откроется страница управления в браузере:
фон, объём, печать, качество, живой вывод Blender и галерея готовых кадров.
Несколько фонов можно поставить в очередь сразу.
[Подробно про панель](mockup/web/README.md).

BAT-файлы никуда не делись и работают как раньше:

- `МОКАП.bat` — спросит четыре вещи в консоли и посчитает кадр;
- `ВСЕ МОКАПЫ.bat` — пересчитает весь набор в финальном качестве.

Готовые файлы ложатся в `mockup/out`, черновики — в `mockup/out/черновики`.
`ОБЗОР.html` собирает все готовые кадры на одну страницу с подписью под каждым.

Фонов сейчас восемь, и стакан во всех один и тот же:

| фон | что это |
|---|---|
| `studio` | серый фотобокс: циклорама, три источника, каталожная камера |
| `living` | гостиная с колонкой |
| `water` | вода и брызги |
| `podium` | подиум |
| `spotlight` | луч в тёмной студии |
| `window` | каменный подоконник, низкое солнце и город за окном |
| `cream` | кремовые скульптурные формы и мягкий тёплый свет |
| `ice` | тающий лёд на тёмной мокрой поверхности |

Имя фона — одно слово: оно же попадает в имя кадра и в командную строку.
Все фоны снимаются одинаково, **512 сэмплов и 1600 px**, чтобы кадры можно было
класть рядом. Номера сцен из арт-дирекшена (S07, S12, S14) лежат внутри файлов
ключом `catalogue`.

Сцены `window`, `cream` и `ice` доступны в `МОКАП.bat` под номерами **6 / 7 / 8**.
[Сравнение с референсами](docs/отчёты/сцены_2026-09-07/СРАВНЕНИЕ.html).
В кадрах пустой стандартный стакан, без изменения материала и геометрии.
Настройки камеры и положения стакана — в соответствующем JSON в `mockup/sets`.

Новый фон добавляется одним файлом, код при этом не трогается:
[как добавить фон](docs/КАК%20ДОБАВИТЬ%20ФОН.md).

## Карта проекта

| Папка | Что внутри |
|---|---|
| `factory/` | Заводские исходники: STEP, OBJ, чертежи PDF. Только чтение. |
| `product/` | Наши модели изделия: `cup410`, `cup500`, `cup650` и сверка `check` |
| `product/cup500/src/` | Общий движок геометрии всех трёх объёмов |
| `mockup/` | Вся съёмка: единый раннер, фоны, свет, печать, рендер |
| `mockup/sets/` | Фоны, по одному файлу на фон |
| `mockup/web/` | Панель управления съёмкой в браузере |
| `mockup/scenes/` | `4.blend` — сцены, из которых берутся фотофоны |
| `mockup/art/` | Макеты печати и технические шаблоны |
| `mockup/out/` | Результаты съёмки: кадр, сцена и отчёт на каждый мокап |
| `library/` | Стакан отдельным файлом для вставки в чужую сцену |
| `ref/` | фотографии изделия; `bg/` — референсы окружения |
| `docs/` | Стандарты, добавление фона, печать, геометрия, отчёты |
| `_архив/` | Прежние версии и снятые с работы ветки |

## Командой, если нужно точнее

```bat
blender -b --factory-startup -P mockup\run.py -- --list
blender -b --factory-startup -P mockup\run.py -- --set studio --cup 500 --print none --render
blender -b --factory-startup -P mockup\run.py -- --set living --cup 650 --print rect --render
blender -b --factory-startup -P mockup\run.py -- --all --render
```

Черновик — `--samples 64 --resolution 700`. Не перезаписывать готовое —
`--output-dir`. Свой макет — `--art путь/к/файлу.png`. Стакан отдельным файлом в
`library` — `--asset`.

`--cup` и `--print` действуют только на один запуск. Чтобы выбор стал
умолчанием, добавьте `--remember`.

## Материал

Материал полипропилена — **один на весь проект**, раздел `pp` в
`mockup/params/shots.json`. Поверхность только преломляет, а молочность живёт в
толще стенки отдельным объёмным рассеянием — как в настоящем литом PP. Отсюда
две вещи, которых поверхностная модель не даёт: сквозь стенку читается то, что
за ней, и толстые места сами выходят плотнее — свёрнутый венчик, поясок у
основания и рёбра расстыковки, утолщающие стенку с 0.5 до 1.8 мм изнутри.

Все кадры всех фонов и всех объёмов снимаются этим материалом, поэтому их можно
класть рядом и сравнивать.

Отдельных художественных материалов в проекте нет: см.
[стандарты работы](docs/СТАНДАРТЫ.md).

**Обновление 2026-09-07:** материал откалиброван по фотографиям `ref`: снижено
избыточное рассеяние, уточнены сатиновая стенка и гладкий венчик, добавлена
слабая процедурная микрофактура. Тот же материал записан в три файла `library/`.
[Разбор и проверки](docs/отчёты/материал_по_ref_2026-09-07.md),
[сравнение до/после](docs/отчёты/материал_2026-09-07/СРАВНЕНИЕ.html).
Проверочный кадр — только `studio`, 650 мл; предыдущие мокапы не перезаписаны.
Ранее сохранённые `.blend` содержат прежний материал; новый применяется при
следующем запуске мокапа или вставке обновлённого стакана из `library/`.

## Что проверено и сохранено

Форма, размеры, клеймо, рёбра и обе UV-развёртки стаканов не менялись.
Прямоугольная печать по `UVPrint` и полная запечатка по `UVMap` работают на всех
трёх объёмах. Заводские исходники лежат нетронутыми в `factory/`, их контрольные
суммы — в `docs/отчёты/protected_files.json`.

```bat
py -3.11 product\check\protected.py
py -3.11 product\check\compare_official.py 410
py -3.11 product\check\compare_official.py 500
py -3.11 product\check\compare_official.py 650
py -3.11 -m pytest product\cup500\tests -q
```

`protected.py` сверяет контрольные суммы заводских исходников — с него стоит
начинать. `compare_official.py` печатает числовой отчёт сверки с заводским STEP;
код возврата 0 значит, что отчёт сформирован, а не что геометрия принята.

## Что снято с работы

Ветка с лимонадом и наполненным стаканом признана неудачной и убрана в
`_архив/lemonade_v2_20260907`. Вместе с ней снят художественный прозрачный
материал `clear_pp`: он рисовал стакан как PET, а не как литой полипропилен.
Стакан во всех кадрах вернулся к материалу из `mockup/params/shots.json`.

Там же снят прежний способ изображать молочность — непропускающей долей
поверхности. По фотографиям изделия видно, что он неверен: сквозь стенку
читается печать с задней стороны, чего вуаль не допускает, а печатный стакан
выходил мутно-серым вместо белого. Мутность переехала в толщу стенки.

Прежние студийные кадры лежат в `_архив/studio_v1_frosted_pp_20260907`, прежние
сцены фотофонов — в `_архив/mockup_out_20260907`. Журнал всех перемещений:
`docs/отчёты/перемещения_2026-09-07.txt`.
