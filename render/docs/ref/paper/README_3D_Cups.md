# Cups · бумажные стаканы в Blender

Модели бумажных стаканов по вашим чертежам и развёрткам Formacia: сцена в Blender с загрузкой макета, студийная съёмка и GLB для просмотрщика cup-viewer.

**Текущая версия — 0.4.** Готовы: **HB80-280** и **DW80-280** (сверены с чертежами, развёртками и фото), **HB62-120**, ряд **HB70-180 / HB70-195 / HB70-210**, **HB80-340**, **HB90-430** и **DW90-430** (чертёж и развёртка, фото не было) , а также **HB72-205**, **HB73-260**, **HB80-360**, **HB90-530**, **DW90-530** и вафельные **EM80-280**, **EM90-430**, **EM90-530** (только развёртка). Черновиков не осталось — собраны все семнадцать артикулов.

У каждого EM две версии:

- `EMxx-xxx` — вафля выдавлена в самой сетке;
- `EMxx-xxx-NM` — обёртка гладкая, вафля лежит картой нормалей и меняется на любой конгрев. Что сделано и что дальше — в [журнале работ](docs/ПРОГРЕСС_МОДЕЛЕЙ_RU.md).

## Быстрый старт

Двойной щелчок:

- `OPEN_HB80-280.cmd` — однослойный стакан;
- `OPEN_DW80-280.cmd` — двухслойный;
- `OPEN_HB90-430.cmd` — 300 мл однослойный;
- `OPEN_DW90-430.cmd` — 300 мл двухслойный;
- `OPEN_HB62-120.cmd` — 120 мл;
- `OPEN_HB72-205.cmd`, `OPEN_HB73-260.cmd` — ряд Ø72;
- `OPEN_HB70-180.cmd`, `OPEN_HB70-195.cmd`, `OPEN_HB70-210.cmd` — ряд Ø70;
- `OPEN_HB80-340.cmd` — 12 oz;
- `OPEN_HB80-360.cmd` — 360 мл;
- `OPEN_HB90-530.cmd` — 400 мл однослойный;
- `OPEN_DW90-530.cmd` — 400 мл двухслойный;
- `OPEN_EM80-280.cmd`, `OPEN_EM90-430.cmd`, `OPEN_EM90-530.cmd` — вафельные, вафля в сетке;
- `OPEN_EM80-280-NM.cmd`, `OPEN_EM90-430-NM.cmd`, `OPEN_EM90-530-NM.cmd` — те же стаканы с конгревом картой нормалей (заменяемый).

Откроется Blender 5.2 со сценой и панелью **N → Cups**:

| Кнопка / поле | Что делает |
|---|---|
| Стакан | список артикулов: без пометки — сверен с фото, «по чертежу» — фото не было, «по развёртке» — нет и чертежа, «черновик» — не разбирался вручную |
| Создать / обновить | строит выбранный стакан заново |
| Загрузить PDF / JPG / PNG | кладёт вашу развёртку на стакан (полный лист шаблона: A4, у EM90-530 — 297 × 235 мм) |
| Показать печать | убирает макет, остаётся чистый картон |
| Конгрев (тиснение) | глубина в мм и загрузка обычного чёрно-белого листа (как у макета): белое выдавливается наружу, край получает фаску. Ложится по той же привязке, что и макет, и уходит в GLB картой нормалей. На EM-NM по умолчанию лежит вафля — загрузка заменяет её |
| Поворот стакана, Ракурс | камеры: каталог, печать, шов, венчик, пятка, дно, внутри, подворот обечайки |
| Сохранить GLB | файл для cup-viewer: материалы `Paper_Print` / `Paper_Inner` / `Paper_Edge` |
| Привязка развёртки к листу | сдвиг X/Y в миллиметрах листа и масштаб, если макет лежит иначе |
| PDF | страница, dpi, скрытие технических слоёв Masks / Info / setka |
| Студия и камеры | пересобирает свет и камеры (серый фотобокс, как у пластиковых стаканов) |

**F12** — рендер, **Ctrl+S** — сохранить сцену вместе с упакованным макетом.

## Что в поставке

По папке на артикул в `output/production/`:

| Файл | Что это |
|---|---|
| `<артикул>.blend` | сцена: стакан, макет Taste Quality, студия, восемь камер |
| `<артикул>.glb` | модель для cup-viewer (0 ошибок валидатора glTF) |
| `renders/` | каталожный кадр 1600 px и ракурсы осмотра |
| `review/` | сравнения с фотографиями, сетка на исходной развёртке, контроль линий шаблона |
| `checks/` | отчёты проверок: геометрия, рабочий процесс панели, валидатор GLB |
| `textures/` | макет, использованный в сцене |

## Где что лежит

| Папка | Что внутри | Трогать? |
|---|---|---|
| `draw/`, `Mockups/`, `images/` | ваши чертежи, развёртки и фотографии | только чтение, не менялись |
| `cup_mockup/` | дополнение Blender: геометрия, материалы, студия, экспорт GLB |  |
| `cup_mockup/params/` | размеры: по файлу на артикул, у каждого числа указан источник | здесь меняют размеры |
| `cup_mockup/params/drafts/` | черновики остальных артикулов | здесь правят черновики |

| `work/inspection/` | растры чертежей и шаблонов, контактные листы фото |  |

## Проверки

```bash
blender -b --factory-startup -P work/v4/build_delivery.py -- HB80-280 --renders
blender -b --factory-startup -P work/v4/check_model.py -- HB80-280 output/production/HB80-280/checks/model.json
blender -b --factory-startup -P work/v4/test_workflow.py -- HB80-280 output/production/HB80-280/checks/workflow.json
node work/v4/validate_glb.js output/production/HB80-280/HB80-280.glb
py -3.10 work/v4/compare_photos.py
```

Для других артикулов — то же с их именем (черновик пишется как `drafts/HB80-340`). Полный список команд и что именно они проверяют — в документах выше.

## Границы точности

Модель воспроизводит конструкцию и укладку макета, а не результат конкретной печати. Цвета в рендере — цвета вашего файла-макета; живая печать Pantone темнее. Скрытые участки (внутренность скрутки, точный профиль подворота) реконструированы: снаружи они не видны. Размеры проверяются против чертежей автоматически, расхождения перечислены в [документе версии 0.4](docs/HB_DW_v0.4_RU.md).
