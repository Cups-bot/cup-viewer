# Панель управления съёмкой

Локальная страница вместо BAT-файлов: выбрать фон, объём, печать и качество,
нажать «Снять» и смотреть, как считается. BAT-файлы остались на месте и
работают как раньше.

```bat
ПАНЕЛЬ.bat
```

Двойной щелчок по нему в корне проекта — откроется браузер. Пока чёрное окно
открыто, панель работает; закрыть — Ctrl+C или закрыть окно.

То же руками:

```bat
py -3.11 mockup\web\server.py
py -3.11 mockup\web\server.py --port 8765 --no-browser
```

## Что она умеет

- выбрать сразу несколько фонов — они встанут в очередь и посчитаются подряд;
- объём, режим печати и свой макет из `mockup/art`;
- три качества, см. таблицу ниже;
- живой вывод Blender с подсветкой строк отчёта, предупреждений и ошибок;
- «Стоп» — снимает очередь и завершает текущий рендер;
- галерея готовых кадров с числами из отчёта: объём, разрешение, размер печати
  на стенке и искажение;
- клик по кадру открывает его целиком.

## Чем отличаются качества

Только двумя числами — сколько сэмплов и какой размер кадра. Всё остальное
одинаково: тот же фон, тот же материал, тот же свет.

| качество | размер | сэмплы | куда ложится | зачем |
|---|---|---|---|---|
| черновик | 700 px | 64 | `mockup/out/черновики` | проверить композицию и посадку, 10–20 с на кадр |
| рабочее | 1200 px | 200 | `mockup/out` | смотреть материал и свет, шум ещё виден |
| финал | 1600 px | 512 | `mockup/out` | сдача |

Сэмплы — это сколько лучей Cycles бросает в каждый пиксель. Мало сэмплов —
зернистость. Шум падает как корень из числа сэмплов: удвоение снижает его
примерно в полтора раза, а время считает вдвое дольше. Размер кадра входит в время квадратом: 1600 px против
700 — это впятеро больше пикселей.

Черновик уходит в отдельную папку и не пересобирает `ОБЗОР.html`: в `mockup/out`
лежат только готовые кадры, иначе обзорная страница смешает финалы и пробы.

Финал не задаёт числа сам — он берёт их из файла фона. Сейчас у всех восьми
фонов там одно и то же, 512 сэмплов и 1600 px, поэтому кадры сравнимы между
собой. Если в каком-то фоне числа поменять, «финал» для него станет означать
другое — это стоит делать только осознанно и сразу для всех.

## Чего она не делает

**Панель не считает ничего сама.** Она собирает те же аргументы, что вы бы
набрали руками, и запускает `mockup/run.py`. Второй логики сборки здесь нет и
заводить её нельзя: иначе панель и командная строка начнут расходиться, и
кадры, снятые разными способами, перестанут быть сравнимыми.

Соответствие однозначное:

| в панели | в командной строке |
|---|---|
| фон | `--set <имя>` |
| объём | `--cup 410 \| 500 \| 650` |
| печать | `--print none \| rect \| cone` |
| макет | `--art mockup/art/<файл>` |
| черновик | `--samples 64 --resolution 700 --output-dir mockup/out/черновики` |
| рабочее | `--samples 200 --resolution 1200` |
| финал | без ключей: 512 сэмплов и 1600 px берутся из файла фона |
| не сохранять .blend | `--no-save` |

Черновики уходят в `mockup/out/черновики`, а не в общую папку: в `mockup/out`
лежат только готовые кадры, иначе обзорная страница смешает в одну ленту финалы
и пробы на 64 сэмплах. По той же причине после черновика `ОБЗОР.html` не
пересобирается.

## Устройство

Один файл сервера на стандартной библиотеке и одна страница. Ни pip, ни
интернета не требуется, внешних библиотек и шрифтов страница не грузит.

| файл | что делает |
|---|---|
| `server.py` | ищет Blender, читает фоны и галерею, держит очередь заданий |
| `index.html` | вся страница целиком: разметка, стиль и скрипт |

Сервер слушает только `127.0.0.1` — снаружи машины он недоступен. Задания
выполняются по одному: видеокарта одна, параллелить нечего.

Файлы отдаются только из `mockup/out`, `mockup/out/черновики` и `mockup/art`, и
только по имени файла — путь из запроса обрезается до имени, подняться выше по
дереву нельзя.

## Если что-то не так

**«Blender не найден»** — панель ищет самую свежую установку в
`C:\Program Files\Blender Foundation\Blender*`. Если Blender стоит в другом
месте, добавьте его в `PATH` или поправьте `find_blender` в `server.py`.

**«Python не найден»** при запуске `ПАНЕЛЬ.bat` — установите Python 3 или
пользуйтесь `МОКАП.bat`: ему Python не нужен.

**Порт занят** — запустите с другим: `--port 8790`.
