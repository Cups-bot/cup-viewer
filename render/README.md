# render/ — движок фотореал-рендера CupViewer

Бывший 3DCupRender. Фотореалистичные мокапы для всех стаканов линейки: бумажных (HB, DW,
EM), пластиковых PP (BM90) и прозрачных PET (PG95). Сцена, стакан, макет,
ракурс — и рендер в Blender Cycles.

**Статус.** С 2026-09-26 — часть CupViewer (концепция — [docs/CONCEPT-v2.md](../docs/CONCEPT-v2.md)):
интерфейс рендера живёт в сайте, этап 4 ТЗ («панель 3DCupRender») отменён. Сейчас:
любой стакан каталога, один или два, в любой из 7 сцен, с выбором ракурса и
формата кадра; превью кадра в браузере совпадает с рендером.

Команды ниже — из папки `render/`.

- [ТЗ](docs/ТЗ.md) — что делаем, этапы, решения
- [Источники](docs/ИСТОЧНИКИ.md) — откуда что пришло и что менялось

## Снять кадр

```bat
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P engine\run.py -- --list
"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup -P engine\run.py -- --set living --cup HB80-280 --render
```

| ключ | что делает |
|---|---|
| `--set <фон>` / `--all` | фон из `sets/` или все рабочие подряд; `ice` выключен (решение владельца), файлы оставлены |
| `--cup <ID>` | стакан из единого каталога `../catalog/cups.json`: `HB80-280`, `DW90-430`, `EM80-280`, `BM90-500` (или `500`), `PG95-520` … |
| `--variant nm` | у вафельных EM: вафля картой нормалей вместо вафли в сетке |
| `--board kraft` | картон бумажного стакана: `coated`, `uncoated` (по умолчанию), `soft-touch`, `kraft` |
| `--proof` | «Имитация картона»: печать бумаги через профиль картона (`catalog/proof`, `bk/proof.py`); в задании — `"proof": true` у стакана; у крафта профиля нет |
| `--art <файл>` | свой макет: бумага — полный лист развёртки PDF/JPG/PNG; PP — поле печати |
| `--page N` | страница PDF |
| `--rotate 75` | повернуть стакан вокруг оси, градусы — нужной стороной дизайна к камере |
| `--print none` | чистый стакан без печати |
| `--second same` | второй стакан — такой же, развёрнут на 150° (пара) |
| `--second bigger` / `smaller` | второй — соседний объём той же серии |
| `--second HB90-430` | второй — любой стакан каталога; `--second-board`, `--second-art`, `--second-rotate` |
| `--layout free --second-pos -95,40` | второй точно в мм от главного: вправо по кадру, вглубь |
| `--job задание.json` | всё сразу: фон, 1–2 стакана, раскладка, качество (для панели) |
| `--camera high` | ракурс из `camera_presets` фона: `front` (как в сцене), `high`, `low`, `left`, `right`; в `studio` — `front`, `level`, `high`, `top` |
| `--frame 4:5` | формат кадра: `1:1` (по умолчанию), `3:4`, `4:5`; длинная сторона — `--resolution` |
| `--samples`, `--resolution` | черновик: `--samples 64 --resolution 700` |
| `--no-save` | не писать `.blend` кадра |
| `--finish` | «камера» (`bk/finish.py`): кривая, ореол бликов, виньетка, резкость, зерно — у кадров сайта всегда |
| `--crop 0.3,0.26,0.7,0.75` | вырез кадра в долях (y снизу): проверить качество в итоговой плотности, не считая весь кадр |

Кадры ложатся в `out/`: картинка, `.blend` сцены и отчёт `.json`.

Масштаб во всех сценах 1:1 к эталонному стакану BM90-500: маленький стакан
ниже большого, как в жизни. Кадр подстраивается под стакан кадрированием, а не
подъездом камеры: камера ракурса стоит на месте, фокусное и сдвиг объектива
выбирают окно (`engine/bk/frame.py`). Поэтому превью в браузере режет тот же
кадр из снимка фона и совпадает с рендером.

Два стакана стоят в одну линию, по центру того места, где стоял один; зазор
между стенками не меньше 3 мм. Место проверяется лучами: под дном опора, над
следом пусто. Камера подстраивается под пару, не поворачиваясь. В `water`,
`podium` и `cream` — один стакан.

## Превью кадра — «Фотореал» сайта

Превью кадра — режим «Фотореал» сайта CupViewer (корень репозитория): сцена,
ракурс, формат, 1–2 стакана, поворот жестом; кнопка «Задание» отдаёт JSON для
`run.py --job`. Стаканы в сцене не двигаются: места выбирает раскладка, та же,
что здесь (`bk/compose.py` ↔ `js/core/photoScene.js`).

Что нужно сайту, выгружается отсюда в `../catalog/scenes/`:

```bat
blender -b --factory-startup -P engine\tools\export_preview.py -- --all
```

Снимки фона по ракурсам, панорама света (лампы видимы — иначе прожектор не
попадает в свет превью), сила солнца, карта площадки. Переснять после любой
правки фона или его ракурсов. Полная выгрузка грузит видеокарту надолго (до 9
минут на ракурс), поэтому на ноутбуке — по шагам: `--meta-only` (без рендера,
секунды), `--pano-only` (только панорама), `--quick --missing --pause 20`
(черновые снимки 1200 px по одному). Сейчас полные снимки только у cream, у
остальных — черновые.

Сверка сайта с рендером — `node tests/photoreal/check.mjs` из корня (сайт
собирает задание и силуэт, Blender по тому же заданию снимает маску —
`engine/tools/preview_mask.py`; приёмка ≤ 2 px).

## Кадр «как с профессиональной камеры» (2026-09-27)

Уровни сайта — **Standard** (2000 px) и **Ultra** (4000 px), размер и цену задаёт
сервер (`server/app/config.py` → `TIERS`), сэмплы — профиль исполнителя
(`server/worker.py`: `laptop` — GTX 1650 Ti, 256; `cloud` — 512 / 1024).

- **Склейка фокуса** (`bk/stack.py`, план — `compose._stack_plan`). Авторские
  камеры сцен снимали на f/2.8–3.5 — резко 1–2 см, стакан плыл по краям.
  Бумажный стакан снимается двумя проходами: фон с авторской диафрагмой
  (стакан невидим для камеры, но отбрасывает тени и отражается; 60 % сэмплов —
  фон размыт) и стакан с диафрагмой «резкий целиком» только в своей рамке; B
  поверх A по прозрачности. Фон тот же, что у снимка превью, — превью и кадр
  совпадают. PET и PP — одна съёмка с диафрагмой посередине по ступеням.
- **Бумага** (`bk/board.py` → `_paper`, `params/boards.json`): облачность
  картона, видимое волокно ~0,7 мм, волна стенки, свой блеск краски на плашках.
- **«Камера»** (`--finish`): S-кривая с опорой на 18 % серого (серая карта
  калибровки на месте, оттенок печати не уходит), ореол бликов, виньетка,
  резкость, зерно под размер кадра. Кадр до неё — 16 бит.

Замер на ноутбуке («Гостиная», DW90-430): Standard — 5,4 мин, видеокарта до 70 °C.

Цвет: один конвейер на все сцены — Khronos PBR Neutral, экспозиция каждой сцены
откалибрована (`engine/tools/calibrate_exposure.py`). В фотобоксе цвет печати на
освещённой стороне — как в файле. Картоны и калибровка — [docs/ref/картоны.md](docs/ref/картоны.md).

## Папки

| папка | что внутри |
|---|---|
| `engine/` | раннер `run.py`, сборка сцен `bk/`, инструменты `tools/`, конфиг `params/shots.json`; `web_old/` — прежняя панель пластика |
| `../catalog/cups.json` | единый каталог стаканов CupViewer — один на сайт и рендер, раздел `render` — для движка; правится руками |
| `sets/` | фоны, по файлу на фон |
| `scenes/` | `4.blend` и текстуры авторских сцен |
| `cups/plastic/` | PP 410/500/650: модели, параметры, сверки |
| `cups/paper/` | 17 бумажных артикулов (+ EM с вафлей картой нормалей) и аддон `cup_mockup` |
| `cups/pet/` | PET PG95-400/520/600 и их сборщик |
| `art/` | образцы макетов и шаблоны полей PP |
| `out/` | кадры; `out/эталоны_сцен/` — эталоны пластика |
| `docs/` | ТЗ, источники, справка по исходным проектам |
| `assets.json` | список тяжёлых файлов вне git (сцены, модели, текстуры, макеты): путь, размер, SHA-256 |

## Тяжёлые файлы

Сцены Blender, модели стаканов, текстуры и тестовые макеты (≈ 500 МБ) в git не
лежат — только их список `assets.json`. Проверить, что всё на месте:

```bat
python engine\tools\assets.py check
```

Добавили или заменили модель, сцену, текстуру — переписать список:
`python engine\tools\assets.py index` и закоммитить `assets.json`.
